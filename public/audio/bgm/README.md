# BGM 試作 v1：林間小棋步

2026-10-18 製作。為鬥獸棋原創的輕柔森林風格背景音樂，**目前僅供試聽，尚未接入遊戲**。

**試聽結果：** 2026-10-18 使用者確認「已試聽，沒問題」。v1 聽感已通過，`approval.json` 記錄這一版音檔的雜湊；重建後音檔內容若改變，manifest 會回到待試聽狀態。

## 試聽

開啟 [BGM 試聽頁](../../audio-preview/bgm.html)，點「播放試作」。預設音量 35%、循環播放；可暫停、繼續、停止、調整音量或關閉循環。

本機網址：`http://127.0.0.1:4175/audio-preview/bgm.html`。若伺服器未啟動，在專案根目錄執行：

```powershell
python -m http.server 4175 --bind 127.0.0.1 --directory public
```

亦可使用專案 Vite 開發伺服器的 `/audio-preview/bgm.html`。播放器以 HTTP 載入 WAV 並使用 Web Audio 播放；直接開啟本機 HTML 的環境可能限制載入，可改用伺服器或直接播放下載音檔。

## 音樂方向

- 曲名：**林間小棋步**。
- 長度：**48 秒**；80 BPM、4/4 拍、C 大調、16 小節。
- 配器：柔和木琴主旋律、短撥弦、輕彈低音、低音量和弦底與稀疏刷奏。
- 結構：四個四小節樂句，依序為主題、變化、稍微抬高與回歸；保留旋律休止，不加入語音、動物叫聲或環境聲。
- 試聽重點：是否適合小朋友思考、是否太熱鬧或單調、循環是否自然，以及旋律長時間重複是否令人分心。
- 此為原創作曲、編曲與程式合成音色，沒有使用外部旋律、錄音或素材庫；無第三方素材署名義務，本文件不另行設定專案授權條款。

## 檔案與循環

| 檔案 | 用途 |
|---|---|
| `forest-little-steps-v1.wav` | 48 kHz、16-bit、雙聲道 PCM 母檔與循環試聽來源 |
| `forest-little-steps-v1.mp3` | 160 kbps、雙聲道壓縮試聽版 |
| `manifest.json` | 長度、循環邊界、音量量測、編碼器與 SHA-256 |
| `score.json` | 音符、配器與起音時間，供重建及後續調整參考 |

WAV 共 2,304,000 個立體聲取樣框；循環區間為 `[0, 2304000)`。跨過結尾的音符與短殘響尾音以週期方式疊回開頭，整首不套淡入淡出，避免每次循環忽然變小聲。試聽播放器只在使用者開始／停止時短淡入淡出，以解碼後的 WAV buffer 循環。

實測整體響度約 **−22.99 LUFS**、真峰值約 **−9.37 dBTP**，首尾取樣跨界差約 **0.00052 full scale**。獨立試聽已通過，和遊戲音效疊播的混音仍留待整合驗收。MP3 在不同播放器的編碼延遲處理可能不同，不以原生 MP3 播放器的重播空隙判定 WAV 循環品質。

## 重建

需要 Python 標準函式庫與 PATH 上含 libmp3lame 的 FFmpeg：

```powershell
python scripts/generate_bgm_preview.py
```

命令會覆寫本目錄的 WAV、MP3、manifest 與 score；不改動已製作的核心音效或動物叫聲。亂數固定種子，同環境可重建一致內容，編碼器版本變更可能改變 MP3 位元組。

這是已通過試聽的第一版試作。尚未實作遊戲內音樂設定、開局切換、音效混音或離線快取。

交付檢查：WAV 格式與精確長度、MP3 解碼長度、檔案雜湊、循環邊界量測、試聽頁 JavaScript 語法及 HTTP 音檔連結均通過；同環境再次產出內容一致。使用者已完成試聽並確認無問題；代理未執行瀏覽器自動化操作驗證。
