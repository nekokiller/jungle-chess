jungle-chess · 美術原型 v0.1

動物棋角色原型

用程式畫出的 Q 版 SVG 動物，沒有用任何圖片檔。這頁用來判斷「每隻動物都會動」的感覺對不對：上面可以單獨觸發每隻動物的表情和動作，下面的小棋盤可以實際走走看。

表情與動作

待機時每隻動物都有自己的小動作，也會隨機眨眼。紅方是實線外框，藍方是珠子外框，不靠顏色也分得出來。

小棋盤試玩

這是正式棋盤的一小塊（7 欄 × 5 列），上方是藍方的陷阱和獸穴。雙方的動物都可以點，不分回合。點一隻動物，再點腳印走過去。

點一隻動物開始吧！

  • 河流（只有老鼠能下水）
  • 陷阱
  • 獸穴

試試看

    動物被吃掉後，按「重新擺放」就會回來。

    這個原型沒有包含的

    • 其他五隻動物（象、虎、豹、狼、狗），畫法會和這三隻一致。
    • 音效和動物叫聲。
    • 回合制、AI 對手和完整的勝負判定（這裡吃光對方不會結束遊戲）。
    • 正式版會改寫成 React 元件並使用 Motion 動畫庫，這裡的表情、動作和節奏可以直接沿用。
