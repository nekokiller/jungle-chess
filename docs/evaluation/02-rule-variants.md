# 鬥獸棋規則變體與差異比較

> 調查日期：2026-10-18
> 鬥獸棋沒有統一的官方規則，各地、各出版商、各網站都有些不同。下表列出常見差異，最後是本專案建議採用的規則。

### 其他較少見的變體

- **動物跳棋（Animal Checkers）**：簡化版，沒有河流和陷阱，只用鼠、狗、虎、象四種。
- **暗棋版**：所有棋子蓋著，翻開才知道是什麼（類似翻翻棋），變成不完全資訊遊戲。
- **狐狸取代狼**：部分地區的棋具用狐狸代替狼。

## 2. 本專案建議採用的預設規則

建議**完全照參考網站的規則集**作為預設，理由：

1. 使用者指定的參考對象就是這個網站，玩法一致比較不會混淆。
2. 這套規則把模糊的地方都定清楚了（水陸邊界、跳河阻擋、重複局面、無子可動），實作上不會有爭議。
3. 「象不能吃鼠」是兒童版棋具最常見的玩法，小朋友比較熟悉「大象怕老鼠」的故事。

預設規則摘要：

- 等級：象 8 ＞ 獅 7 ＞ 虎 6 ＞ 豹 5 ＞ 狼 4 ＞ 狗 3 ＞ 貓 2 ＞ 鼠 1，同級可以互吃。
- 鼠能吃象（只限陸地），象不能吃鼠（鼠在我方陷阱時除外）。
- 只有鼠能下河；水陸之間不能互吃。
- 獅和虎都能縱跳和橫跳；路徑上有任何一隻鼠就不能跳。
- 敵方動物在我方陷阱裡時等級變 0。
- 獲勝：進入敵方獸穴／吃光敵方／對方無合法走法。
- 和棋：同一局面（含輪到哪一方）第三次出現。

### 之後可以考慮的「家庭規則」開關（非必要）

如果之後想讓爸媽和小朋友自訂玩法，可以把下面幾項做成選項，預設都關閉：

| 開關 | 說明 |
|---|---|
| 象可以吃鼠 | 傳統中國規則 |
| 獅虎同級 | 獅和虎可以互吃 |
| 虎不能橫跳 | 較舊的規則 |
| 無子可動改判和棋 | Leiden 版 |
| 步數上限判和 | 例如 200 步內沒分出勝負就和棋，避免小朋友的對局拖太久 |
