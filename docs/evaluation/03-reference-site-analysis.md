# 參考網站分析：AI Games Spark 鬥獸棋

> 調查日期：2026-10-18（網站頁面標示最後更新 2026-10-02）
> 網址：<https://aigamespark.com/?lang=zh-TW>　鬥獸棋介紹頁：<https://aigamespark.com/zh-tw/鬥獸棋/>
> 資料來源：網站公開頁面文字，以及瀏覽器載入的前端 JavaScript（規則引擎、AI worker、多語系字串）。
> **注意**：以下程式行為只是用來理解規則和設計，本專案應自行撰寫程式，不要複製對方的程式碼。

## 1. 網站概況

- 名稱：AI Games Spark（東方棋類遊藝館），免費、免下載、手機和電腦瀏覽器都能玩。
- 收錄棋類：中國象棋（含殘局）、翻翻棋、軍棋、鬥獸棋、五子棋、國際象棋、國際跳棋。
- 支援 14 種語言（含繁中、簡中、英、日、韓等）。
- 鬥獸棋標語：「童年策略」、「河谷爭穴」、「河流、陷阱與八種動物的等級博弈」。

## 2. 遊戲模式

| 模式 | 內容 |
|---|---|
| **人機對戰（本機 AI）** | 六檔難度，免登入。AI 在瀏覽器的 Web Worker 中計算。 |
| **AI 對弈（雲端 AI）** | 本機引擎先算出合法候選著和分數，再交給雲端 AI「研判」挑一步。雲端無法使用時改用本機備用 AI（頁面說明：難度可能降低）。 |
| **雙人對戰** | 線上自動配對；建立房間後分享房間號碼或邀請連結給好友（另一台裝置）；輸入房間號碼加入。網站說明頁另提到「同螢幕對弈」。 |

## 3. 開局設定

- 選擇難度（六檔）。
- 選擇執**紅方**或**藍方**。
- 選擇**先手**或**後手**。
- 程式內部：紅方＝第 0 方，在棋盤下方；藍方＝第 1 方，在上方；預設由第 0 方（紅）先走，再依玩家的先後手選擇調整。

## 4. AI 六檔難度

介面名稱（繁中）：**入門、簡單、中等、困難、高手（或「專家」）、大師**。

本機 AI 參數（從前端程式讀出）：

| 難度 | 內部代號 | 搜尋深度 | 每步時間上限 | 隨機擾動 |
|---|---|---|---|---|
| 入門 | novice | 1 | 18 ms | 110 |
| 簡單 | easy | 2 | 45 ms | 45 |
| 中等 | medium（預設） | 3 | 100 ms | 12 |
| 困難 | hard | 4 | 220 ms | 0 |
| 高手 | expert | 5 | 480 ms | 0 |
| 大師 | master | 6 | 900 ms | 0 |

### 4.1 AI 演算法要點

- **搜尋**：迭代加深（深度 1 到上限）的 Negamax ＋ Alpha-Beta 剪枝，搭配置換表（transposition table），時間到就停，用上一層完整結果。
- **重複局面**：搜尋時會記錄局面出現次數，會造成第三次重複的走法評為 0 分（和棋）。
- **立即獲勝**：能走進敵方獸穴或吃光對方的走法直接給極大分數。
- **隨機性（讓低難度比較「笨」）**：從分數前 4 名的候選著中，每一個加上 ±(擾動值÷2) 的隨機分數再重新排序。擾動值越大，越常選到不是最好的一步。困難以上沒有隨機性。
- **棋子價值**：鼠 125、貓 190、狗 245、狼 310、豹 385、虎 510、獅 560、象 590。（鼠的價值比貓、狗低，但因為能吃象和下河，實際上很重要。）
- **局面評估**：
  - 子力（上面的棋子價值）
  - 前進加分：越接近敵方底線，每列加 10 分
  - 中央加分：越靠近 d 欄，每欄加 3 分
  - 站在敵方陷阱裡扣 150 分
  - 機動力：我方合法走法數 − 對方合法走法數，每步 4 分
- **走法排序**（讓剪枝更有效）：進敵方獸穴最優先；吃子依「被吃子價值 − 攻擊子價值×0.08」排序；走進敵方陷阱扣分；往前走加分；跳河加分。

### 4.2 對本專案的參考價值

- 六檔難度的差別主要靠「搜尋深度＋時間上限＋隨機擾動」三個參數，做法簡單，很適合照這個思路自己實作。
- 對小朋友來說，入門和簡單兩檔應該要**真的會犯錯**（例如會把棋子送進陷阱、會錯過吃子），小朋友才有機會贏。

## 5. 介面與操作

| 功能 | 說明 |
|---|---|
| 走棋方式 | 點自己的棋子 → 顯示所有合法落點 → 點落點完成 |
| 合法落點提示 | 選中棋子時把可以走的格子都標示出來 |
| 錯誤提示（toast） | 走錯時告訴玩家原因（見下表），對學習規則很有幫助 |
| 提示（Hint） | 顯示建議走法，用青色虛線路徑畫出來 |
| 悔棋／重做 | 人機對戰時悔棋會一次退回兩步（玩家＋AI 各一步）；線上雙人對局不能悔棋 |
| 翻轉棋盤 | 可以把棋盤上下翻轉 |
| 計時 | 有對局計時 |
| 棋譜 | 記錄每一步，例如「虎 a1→a2」，跳河和吃子有不同寫法 |
| 外觀 | 紅、藍棋子除了顏色，還用不同外框形狀區分（色盲友善） |
| 鍵盤操作 | 方向鍵移動游標，Enter 或空白鍵選子／落子；有螢幕閱讀器說明文字 |
| 音效 | 走棋、吃子有音效 |
| 對局結束 | 顯示勝負原因：「進入敵方獸穴獲勝」「吃光敵方動物獲勝」「對方無合法著」「三次重複局面和棋」 |

### 5.1 走錯時的提示訊息（原文）

| 情況 | 訊息 |
|---|---|
| 一般不合法 | 該動物不能這樣走。 |
| 目標有己方棋子 | 目標格已有己方動物。 |
| 想進己方獸穴 | 動物不能進入己方獸穴。 |
| 非鼠想下河 | 只有鼠可以進入河流。 |
| 鼠跨水陸吃子 | 鼠不能隔著河岸跨水陸吃子。 |
| 跳河被擋 | 河中有鼠，獅虎不能跳河。 |
| 等級不夠 | 目標動物等級更高，無法吃子。 |

## 6. 網站上的入門建議

> 用鼠控制河道，用低級動物保護陷阱附近，別只按等級交換。

## 7. 學術背景（補充）

- 一般化（任意大小棋盤）的鬥獸棋已被證明是 **EXPTIME-complete**（2019 年 arXiv 論文）。
- van Rijn 與 Vis（2013）建立了 4 子殘局資料庫，Bohrweg（2016）建立了 7 子殘局資料庫。
- 對本專案而言，標準 7×9 棋盤用一般的 Alpha-Beta 搜尋就足以做出很強的 AI，不需要更複雜的技術。
